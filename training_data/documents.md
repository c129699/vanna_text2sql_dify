# 政务服务实施清单数据库文档

## 表结构说明

### info_fwsx_ssqd 表

该表用于存储政务服务实施清单的详细信息，是政务服务系统的核心数据表。

#### 主要字段说明

- **matter_name**: 事项名称，这是政务服务事项的核心标识，必填字段
- **ssqd_code**: 实施清单编码，唯一标识每个实施清单
- **ssqd_dept_name**: 实施主体部门名称，指明该事项由哪个部门负责办理
- **accept_condition**: 受理条件，描述办理该事项需要满足的条件
- **is_charge**: 是否收费标识，0表示不收费，1表示收费
- **promise_time**: 承诺办结时限，说明该事项承诺在多长时间内办结
- **hanle_form_name**: 办理形式名称，如在线办理、窗口办理等
- **is_book**: 是否支持预约，0表示不支持，1表示支持
- **hanle_time**: 办理时间，说明具体的办理时间段
- **hanle_addr**: 办理地点，指明在何处可以办理该事项
- **zx_phone**: 咨询电话，提供咨询方式
- **ts_phone**: 监督投诉方式
- **hanle_proc**: 办理流程，描述详细的办理步骤
- **enactment**: 设定依据，说明该事项设立的法律法规依据

#### 行政区划相关字段

- **xzqh_code**: 行政区划编码（区县级别）
- **xzqh_parent_code**: 行政区划上级编码（地市级别）
- **xzqh_jb**: 行政区划级别，1表示省级，2表示地级市，3表示区县
- **xzqh_name**: 行政区划名称

#### 业务规则

1. **删除标记**: `del_flag` 字段标识记录是否已删除，'0'表示正常，'1'表示已删除。查询时通常需要过滤已删除的记录。
2. **可用办事项**: 可用办事项是指 `del_flag = '0'` 的记录，表示当前可办理的事项。
3. **事项查询**: 可以通过事项名称、部门名称、行政区划等维度进行查询。
4. **统计信息**: 可以统计某个区域、某个部门的可用办事项数量。

#### 常用查询场景

1. 查询所有可用办事项的总数
2. 查询某个部门的办事项列表
3. 查询某个地区的办事项
4. 查询支持在线办理的事项
5. 查询免费办理的事项
6. 根据事项名称模糊查询

#### 注意事项

- 文字类型用模糊查询
- 时间相关字段可能是字符串格式，需要注意类型转换
- 咨询电话和监督电话字段可能为空
